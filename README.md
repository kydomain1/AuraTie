# AuraTie - Premium Lifestyle Blog Website

A comprehensive lifestyle blog website featuring magazine-style design with six main categories: Fashion & Accessories, Health & Beauty, Home & Garden, Travel & Accommodation, Finance & Insurance, and Food & Beverage.

## Features

### Design & Layout
- **Magazine/Editorial Style**: Clean, professional layout emphasizing typography and high-quality imagery
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean lines, sophisticated color scheme, and elegant typography
- **Smooth Animations**: CSS transitions and JavaScript animations for enhanced user experience

### Content Management
- **6 Main Categories**: Comprehensive coverage across lifestyle topics
- **5 Featured Articles**: High-quality content with publication dates from Jan-Aug 2025
- **Product Reviews**: Detailed product pages with specifications, reviews, and ratings
- **Search Functionality**: Advanced search across all content
- **Pagination**: Efficient content browsing with pagination controls

### Key Pages
- **Homepage**: Featured content, category showcase, trending articles
- **Search Page**: Dedicated search interface with advanced filtering and sorting
- **Article Pages**: Individual article pages with rich content and related items
- **Category Pages**: Filtered content by category with sorting options
- **Product Pages**: Detailed product information with reviews and specifications
- **About Page**: Team information and company values
- **Contact Page**: Contact form with FAQ section

### Technical Features
- **Pure HTML/CSS/JavaScript**: No framework dependencies
- **SEO Optimized**: Proper meta tags, semantic HTML, and structured content
- **Fast Loading**: Optimized images and efficient code structure
- **Cross-browser Compatible**: Works across all modern browsers
- **Accessibility**: ARIA labels and keyboard navigation support

## Customization

The website is built with modular CSS and JavaScript, making it easy to:
- Modify colors and typography in `styles/main.css`
- Add new articles by updating the data in `scripts/main.js`
- Customize layouts by editing the respective CSS files
- Extend functionality with additional JavaScript modules
